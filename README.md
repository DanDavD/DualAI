# DualAI

A cross-platform real-time interpretation and translation tool designed for interpreters and multi-language conversations.

## Tech Stack
- **Desktop Runtime:** Electron
- **Bundler & Build Tool:** Vite (via electron-vite)
- **Frontend:** React 19 + TypeScript
- **Styling:** Tailwind CSS v4
- **Package Manager:** pnpm

## Getting Started

### Prerequisites
- Node.js (v18+)
- pnpm (v9+)

### Installation
```bash
pnpm install
```

### Development
```bash
pnpm run dev
```

### Production Build
```bash
pnpm run build
```
